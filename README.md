# Evidence Reviewer Bot policies — drafts

These are **draft documents**, not approved Terms of Service or a final Privacy Policy. Do not enable GitHub Pages or submit policy URLs to Discord until all placeholders and factual uncertainties are resolved.

## Required before publishing
- Confirm the legal or business operator name and a working support/privacy contact address.
- Confirm actual data fields, service providers, retention periods, deletion handling, and logging, including n8n, Discord, Google Sheets/Drive, and Cloudflare.
- Remove draft warnings, set an effective date, and review final policies.

## Publishing (after finalization)
GitHub repository **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

Then test:
- https://dianaprincipe.github.io/tta-discord-bot-policies/terms.html
- https://dianaprincipe.github.io/tta-discord-bot-policies/privacy.html

After successful deployment, add the URLs in **Discord Developer Portal → Evidence Reviewer Bot → General Information**.

Discord team owner identity verification is separate and must be completed personally.
